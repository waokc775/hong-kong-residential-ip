## 买之前先分清：住宅IP VPS 和住宅代理池

同样叫“香港住宅IP”，市面上其实有两种完全不同的东西，买错品类比买贵套餐更浪费钱。

第一种是代理池服务，按流量或套餐计费，IP会在请求之间轮换，或者少量共享。Bright Data 的香港代理属于这类，住宅、数据中心、移动几种类型都有，按GB计费，主要面向批量抓取公开数据；ipipgo 主打金融交易场景的独享住宅代理，它对“独享”的定义是每个IP最多保留3个用户，仍带有共享成分。

第二种是住宅IP VPS：你租下一整台位于香港的服务器，拿到一个固定不变的IP，直接来自HGC或iCable的居民宽带段。需要“长期、稳定、同一个IP”的场景——挂店铺账号、运营社媒、看TVB、抢票——VPS是对的选择；需要海量IP轮换的爬虫场景，代理池才合理。下文讲的都是第二种。
